# Hardware-Piano-Tiles
The objective of the project is to design and build a hardware-based, 4-column Piano Tiles arcade game without using any microcontroller, FPGA, or software-controlled processor. Instead of programming the game behavior, the system implements the game mechanics directly through 74-series logic ICs.

Digital logic circuits form the foundation of modern computing systems, interactive hardware, and real-time control applications. Even simple digital systems can demonstrate important ideas such as clocked behavior, sequential memory, combinational decision-making, state storage, and user interaction. This project applies these concepts by implementing a simplified version of the popular game Piano Tiles using only discrete digital logic components.

In the proposed system, falling tiles are represented using LEDs arranged in a 4-column display grid. Each column corresponds to one player input button. A master clock controls the downward movement of the tiles, while a separate high-speed counter and decoder circuit generates pseudo-random tile placement. When a tile reaches the bottom row, the player must press the corresponding button. If the button press matches the tile position, the system registers a successful hit and increments the score. If the player presses the wrong button or misses a tile, the system enters a Game Over state.
The system is divided into several functional blocks: master clock generation, pseudo-random tile generation, LED display movement, player input and debouncing, collision detection, score counting, difficulty selection, and Game Over state control. The design demonstrates both sequential logic, such as counters, shift registers, and latches, and combinational logic, such as AND/OR gates used for hit detection, false-press detection, and Game Over generation.
